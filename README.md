# Core Concepts and Skills - Mini Projects

Phase 2 of my internship. Three small projects, each demonstrating a core concept, plus unit tests.

| Project | File | Concepts practiced |
|---|---|---|
| Calculator | `src/calculator.py` | Functions, type hints, error handling |
| To-Do List | `src/todo.py` | Classes, lists, dictionaries, loops, validation |
| Text Utilities | `src/text_utils.py` | Strings, recursion, comprehensions, `collections.Counter` |

## Run
```bash
python src/calculator.py
python src/todo.py
python src/text_utils.py
```

## Test
```bash
python -m unittest discover -s tests -v
```
